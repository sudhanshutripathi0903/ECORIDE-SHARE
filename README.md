# CarpoolGo 🚗

> **Ride together. Save together.**

A modern carpooling web app that connects drivers with passengers travelling the same route — safer, cheaper, and greener than solo commuting.

![Status](https://img.shields.io/badge/status-active-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔍 **Smart Ride Search** | From, To, Date, Seats — instant results |
| 👤 **Verified Profiles** | Govt ID + background check for every driver |
| 📍 **Live GPS Tracking** | Share your route with family in real time |
| 💬 **In-app Chat** | Talk to your driver without sharing your number |
| 🆘 **SOS Alerts** | One-tap emergency button |
| 💳 **UPI Payments** | Auto fare split, no awkward math |
| 👩 **Female-only Filter** | Extra safety option for women |
| 🌱 **Carbon Savings** | Track how much CO₂ you've saved |

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom design system
- **JavaScript** — vanilla, no frameworks
- **Tailwind CSS** (CDN) — utility classes
- **Google Fonts** — DM Sans + Fraunces
- **Lucide Icons** (optional)
